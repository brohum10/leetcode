# Algorithm Practice Archive

This repository contains my earlier Python solutions to common data-structure and algorithm exercises. It is retained as a record of progression and has been superseded by my organized, automatically synced [NeetCode solutions](https://github.com/brohum10/neetcode-submissions).

## Topics represented

- Arrays, hashing, strings, and two-pointer techniques
- Linked lists, stacks, queues, heaps, and cache design
- Binary trees, binary-search trees, DFS, and recursion
- Binary search, sliding windows, greedy scheduling, and backtracking

The files intentionally preserve the original problem-solving attempts, including brute-force and optimized variants. They are interview-practice snippets rather than a packaged application.

## Running a solution

Most files follow the online-judge convention where structures such as `TreeNode` or `ListNode` are provided by the platform. Standalone scripts can be run with Python 3:

```bash
python3 valid_anagram.py
```
